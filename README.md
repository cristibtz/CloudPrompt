## Setup .env file
```.env
#AWS Credentials
AWS_ACCESS_KEY_ID=
AWS_SECRET_ACCESS_KEY=

#OPENAI Configs
MODEL=gpt-4o-mini
OPENAI_API_KEY=

#Logfire token
LOGFIRE_TOKEN=

#LangSmith OpenTelemetry variables
LANGSMITH_TRACING="true"
LANGSMITH_ENDPOINT="https://api.smith.langchain.com"
LANGSMITH_API_KEY=""
LANGSMITH_PROJECT=""
```
